# Jordan — Personal Training Website

This is a small static site for Jordan's personal training service. It includes:

- `index.html` — hero with headshot and intro, "Words from your trainer" section, and contact.
- `styles.css` — responsive styles and top contact bar.
- `script.js` — smooth scroll for CTA.
- `headshot.jpg` — place your photo in the project root (already uploaded by the assistant).

Quick steps to push this project to GitHub and deploy on Vercel:

1. Create a new repository on GitHub (public or private) named `pt-website` (or your preferred name).
2. In your local project folder run:

```bash
git remote add origin https://github.com/<your-username>/<your-repo>.git
git branch -M main
git push -u origin main
```

3. On Vercel: use "Import Project" → select the GitHub repo → deploy (default settings work for a static site).
